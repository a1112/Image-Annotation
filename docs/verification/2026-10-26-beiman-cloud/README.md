## 验收中观察到的限制

- iPad 的审阅 Outbox 已 synced，服务器审阅及标注版本正确，界面待上传 0、冲突 0、在线；但该图片行残留 `dirty=1 / sync_status=pending`。只读检查定位为 QA ack 没有清理图片附属同步标记，实际没有待发送的操作。本轮未直接改数据库掩盖该状态，也未修改正在并行开发的同步源码。
- 任务主记录的“待分配”与图片项的“已通过”分开保存；本次流程以 task item 和按标注版本记录的 QA review 为准。
- 手机打开中的工作台不会立即刷新其他设备的审阅文案；重新打开样本后显示“通过”。底层 SQLite 已先收到 server-4。
- 桌面首次下载全量 bootstrap 发生网络发送错误，第二次成功。桌面缓存已逐项复核；同一工作区另一项活动任务编辑 DataProjectHome.tsx 曾造成临时 JSX 编译错误，随后自行恢复。桌面现已实际看见云端 6,036 图/4 类，以及样本原图、两个框、X=285.1 和“通过”状态；工作台工具栏布局仍受并行样式修改影响，本轮未替其他任务改源码，也未将数据回读视为完整桌面视觉回归通过。
- 本轮移动运行证据为 **iPhone / iPad 模拟器**。Android 真机及 iOS 真机签名安装按既有决定待设备/签名可用；本轮没有重新构建 APK/IPA，也没有把包构建当成真机运行证据。
