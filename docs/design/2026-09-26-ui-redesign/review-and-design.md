## 审查发现（按优先级）

### P1：缩略图切换会丢弃未保存的标注
位置：src/App.tsx:3875；对照 src/App.tsx:3337、3086–3103。
底部缩略图直接调用 setActiveImageId，没有复用 goToImage 的 dirty 确认。
修改当前对象后点击另一张缩略图，新图片的异步加载会覆盖 objects 并清除 dirty。
建议所有切图入口共用一个保存/放弃/取消流程，同时避免异步旧响应覆盖当前图片。
此结论基于源码路径审查；本次没有连接真实数据后台进行复现。

### P2：多个看起来可用的控件没有对应功能
位置：src/App.tsx:960–972、1007–1011、3764–3792、3970–3973。
主导航没有点击处理，数据集筛选固定选中“全部”；智能工具和显示映射到 select 模式；
标注页的“导出 COCO (JSON)”没有点击处理。
建议只展示已接入功能。质检、快照、导出保留项目级导航；导出复用现有项目导出流程。
工具栏保留选择、矩形、多边形、平移，避免暗示尚不存在的能力。

### P2：后置桌面样式覆盖窄屏标注布局
位置：src/styles.css:2904–2907、3777–3779。
960px 媒体查询设置两列，后面的同等优先级规则再次把 annotation-page 设置成
58px / flexible / 306px 三列，因此在窄屏也会覆盖原本两列规则。
建议合并同一组件样式，桌面基础在前、断点规则在后；以实际计算样式和截图验证。
本次未连接数据后台验证窄屏画布渲染，结论依据 CSS 级联。

### P2：默认测试范围误收集其他工作树
位置：vitest.config.ts:5–8。
npm test 实际发现 .worktrees 下两份其他 checkout 的 8 个测试套件，加载失败导致退出 1。
独立 vitest.config.ts 没有 include 限制，exclude 也未排除 .worktrees。
建议将测试范围限定当前 src，并显式排除其他工作树；不对工作树本身做删除或移动。

### P3：样式测试与最终生效样式脱节
位置：src/styles.test.ts:7–9、14–20；src/styles.css:851、3122。
cssBlock 用首次正则匹配提取规则。测试要求 dataset-card 有渐变，但后面的同名规则已覆盖为白色。
测试通过不能证明真实界面符合断言。建议用浏览器计算样式和关键尺寸截图验证布局，
避免继续把某段 CSS 字符串当成视觉正确性的证明。

## 方案比较

| 方向 | 优点 | 代价 |
| --- | --- | --- |
| 浅色管理 + 深色画布（推荐） | 表格可读，图像突出，贴近现有工作流 | 需要统一布局和组件样式 |

## 推荐设计

### 全局结构
标题栏保留桌面拖动区和窗口按钮，内容区保持独立。
全局导航只提供数据集和后台任务等真实入口；项目内使用八个已有标签页。
主要动作使用蓝色，成功为绿色，待处理为琥珀色，错误为红色，同时提供文字状态。
中文为主，格式、文件名与类别名保留原值。

### 数据集首页
沿用真实缩略图和数据，卡片突出名称、图片数、完成度及待审核数。
“打开”作为主入口，独立窗口等次要动作收进明确的菜单。
筛选必须接入真实条件，未实现项移除或明确禁用。
空数据、加载、导入失败、后端不可用分别提供对应说明和恢复入口。

### 数据集概览
见 dataset-overview.png。
项目上下文、主动作和标签导航组成稳定页头。
统计带、进度与待办、最近样本和类别分布构成阅读顺序。
图中的 1280/960/320 等仅是示例。真实计数来自 ProjectDetail；依据百分比推算的数量应标为约数。
类别分布来自类别对象计数，百分比分母使用明确的对象总量，不能与图片总数混用。
现有当前页样本密度图若保留，应标“当前加载样本”，不宣称全量时间趋势。
队列分类可能重叠，不将待标注、待审核、质量问题简单加成一个去重总数。

### 标注工作台
见 annotation-workspace.png。
56px 工具列 + 自适应深色画布 + 280px 属性面板，底部连续缩略图。
顶部突出文件上下文、未保存状态、上/下一张、提交质检、保存标注。
保留已有保存并下一张能力，可放到保存动作的次级菜单，避免三个同等强调的保存入口。
属性区分对象属性和图片信息；标注对象颜色与画布一致。
所有切图入口处理未保存内容，只有保存命令成功后才显示已保存。
分类任务用类别选择替代几何工具；检测和分割保持现有交互能力。
底部队列应围绕当前项展示，避免一直只显示前 12 张。
图中的容量、页数、缩放和坐标为示例；文件大小在真实接口未提供时不展示。

### 视觉规范
背景 #F5F7FA，面板 #FFFFFF，文字 #17212F，次要文字 #667085，边界 #E2E6ED。
主色 #2463EB，画布 #20262C，成功 #159570，警告 #D98B15，错误 #D94C4C。
正文 13–14px，页面标题 22–24px，数字等宽；圆角 6–8px，间距按 4/8px 递进。
避免装饰渐变、过多阴影、重复进度图和技术运行时术语。
聚焦框、错误文字、禁用原因、键盘操作与中文可读性必须保留。

### 响应式与边界状态
1440/1280px 保持三列标注区；1024px 压缩次要操作，保障画布宽度。
960px 以下属性区移至可折叠下方区域；栏内独立滚动，工具栏允许换行。
测试长文件名、无对象、多对象、保存失败、后端断开、空类别、空数据集及未保存切图。
重设计保留现有 Tauri 拖动区与窗口控制行为。

## 实施边界与验证计划

先集中布局 tokens 和组件样式，再调整 JSX 信息结构，复用现有 API；
避免直接重写所有标注状态逻辑。异步切图及保存保护作为独立行为修复验证。
不引入新的组件库或后端协议，不用生成图片充当真实数据样本。
按数据集首页 → 项目概览 → 标注页 → 质检及弹窗的顺序统一样式。
为切图防丢失、导航与筛选增加有意义的行为测试；在真实后台上检查绘制、保存和导出。
最终验证 1440、1280、1024 和 900px 视口，检查实际布局而非仅匹配 CSS 字符串。
